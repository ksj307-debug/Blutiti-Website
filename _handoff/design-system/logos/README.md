# Logos

블루티티 공식 로고 2종 × 3색. 원본 PNG를 벡터(SVG)로 변환했고, 색상은 디자인 시스템 토큰에 맞춰 재지정.

## 형태별 용도

| 형태 | 파일 | 쓰는 곳 |
|---|---|---|
| 가로형 BLUTITI SELFIE STUDIO | `blutiti-horizontal-*` | 웹사이트 데스크톱 헤더(높이 20~24px), 푸터, 예약 확인 페이지 상단, 이메일·카카오 알림 이미지 헤더, 네이버 플레이스·블로그 배너, 가로 현수막 |
| 세로형 BLUTITI / Selfie Studio | `blutiti-stacked-*` | 모바일 헤더(높이 32~40px), 히어로 사진 위 로고, 인스타그램 프로필·게시물 워터마크, 당근마켓 광고 이미지, 정사각 썸네일, 명함·포토카드·인화 봉투 |

판단 기준: 가로 공간이 세로의 6배 이상 → 가로형, 그 외(정사각·세로·좁은 화면) → 세로형.

## 색상별 용도

| 색 | 토큰 | 배경 |
|---|---|---|
| navy (#3c4479) | `titi-navy` | 기본값. `paper-100`, `paper-200`, `mist`, 밝은 컬러 사진 |
| ink (#1c1b19) | `ink` | 흑백 인쇄물, 흑백 사진 위, 1도 인쇄(도장·스티커) |
| ivory (#f7f4ee) | `on-night` | `night` 블랙 섹션, 어두운 사진 위, 다크 테마 |

- 다크 테마에서는 navy 대신 ivory 사용
- 로고에 `titi-cobalt` 등 다른 색 사용 금지, 그라데이션·그림자·외곽선 금지
- ivory 파일은 밝은 타일에서 보이지 않는 것이 정상

## 규격

- 여백: 사방으로 대문자 B 높이만큼
- 최소 크기: 가로형 높이 14px, 세로형 높이 28px (화면 기준)
- 웹은 SVG 사용, SVG를 못 쓰는 곳(카카오 알림, SNS 업로드)은 PNG(2~3배 해상도, 투명 배경)
- `*-original.png`: 받은 원본 그대로 보관. 가로형 원본은 네이비, 세로형 원본은 블랙(#151515)
- 비율 변형·자간 조정·텍스트로 재현 금지
